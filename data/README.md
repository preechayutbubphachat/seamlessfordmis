# Data Directory

โฟลเดอร์นี้เก็บไฟล์ต้นทางของฐานประวัติการรักษาหลักที่ระบบใช้ sync เข้าฐานข้อมูล

หลักการใช้งาน:
- ใช้ไฟล์ Excel ต้นทางที่เชื่อถือได้เท่านั้น
- ระบบจะตรวจ `SHA-256`, ชื่อไฟล์, ขนาดไฟล์, และเวลาแก้ไขก่อน sync
- ห้ามแก้ค่าด้วยมือหลังจากวางไฟล์แล้วโดยไม่บันทึกเวอร์ชัน
- ถ้าโครงสร้างคอลัมน์เปลี่ยน ต้อง review importer ก่อนใช้งาน

ไฟล์ตัวอย่างมาตรฐานสำหรับ MVP:
- `main_history.xlsx`

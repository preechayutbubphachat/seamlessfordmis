# UI Labeling

## คำหลักที่ควรใช้

- ฐานข้อมูลการตรวจโรค
- กลุ่มเป้าหมาย
- พบประวัติในรายการที่เลือก
- ไม่พบประวัติในรายการที่เลือก
- ตัวระบุไม่ถูกต้อง
- ไม่มีข้อมูลตัวระบุ
- ยังไม่เคยตรวจ
- ตรวจแล้วแต่เกินกำหนด
- ตรวจแล้วและยังไม่เกินกำหนด
- ต้องตรวจสอบ
- ข้อมูลจากไฟล์กลุ่มเป้าหมาย
- ที่มาข้อมูล
- ไฟล์ต้นทาง
- แถวต้นทาง
- วิธีจับคู่

## วิธีจับคู่

- `identifier_exact` -> `ตรงจากเลขตัวระบุ`
- `name_exact_secondary` -> `ตรงจากชื่อ (สำรอง)`
- `needs_review` -> `ต้องตรวจสอบ`
- `not_found` -> `ไม่พบข้อมูล`

## เพศ

- `male` -> `ชาย`
- `female` -> `หญิง`

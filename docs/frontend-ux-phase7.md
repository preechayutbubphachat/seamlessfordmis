# Frontend UX Phase 7

เอกสารนี้สรุปแนวทาง UX ของหน้าแสดงผลกลุ่มเป้าหมายหลัง Phase 7

## Information Hierarchy

หน้า target group detail ควรแสดงข้อมูลตามลำดับนี้:

1. ข้อมูลภาพรวมของกลุ่มเป้าหมาย
2. ตัวเลือกโรคหรือบริการที่ต้องการค้นย้อนหลัง
3. summary cards เชิงธุรกิจ
4. filter และ search สำหรับผลรายบุคคล
5. ตารางผลรายบุคคล
6. รายละเอียดเชิงเทคนิค เช่น import/match/preview ในส่วนรอง

## Summary Cards

summary cards หลักที่ต้องแสดง:

- จำนวนกลุ่มเป้าหมายทั้งหมด
- จำนวนที่พบประวัติในรายการที่เลือก
- จำนวนที่ยังไม่พบประวัติในรายการที่เลือก
- จำนวนตัวระบุไม่ถูกต้องหรือไม่สมบูรณ์
- coverage %

## Result Filters

filters หลัก:

- ทั้งหมด
- พบประวัติ
- ไม่พบประวัติ
- ตัวระบุไม่ถูกต้อง
- ไม่มีข้อมูลตัวระบุ
- ต้องตรวจสอบ

สามารถใช้ค้นหาเพิ่มด้วย CID หรือชื่อ-สกุล

## Empty And Error States

- ถ้ายังไม่เลือก service:
  - แสดงข้อความให้เลือกอย่างน้อย 1 รายการก่อนสร้างผลลัพธ์
- ถ้ายังไม่มีผลลัพธ์:
  - แสดง empty state ที่บอกขั้นตอนถัดไปชัดเจน
- ถ้า query แล้วไม่พบรายการใน filter:
  - แสดงว่าไม่พบรายการในเงื่อนไขที่เลือก
- ถ้า backend ตอบ error:
  - ใช้ข้อความภาษาไทยที่อธิบายเชิงปฏิบัติการ ไม่ใช่ error เชิงเทคนิคล้วน

## Technical Detail Placement

ข้อมูลเชิงเทคนิคยังต้องอยู่ในหน้า แต่ควรถูกลดระดับเป็น:

- expandable section
- secondary panels
- debug/info blocks

เพื่อให้หน้าหลักสื่อ business outcome ก่อน
